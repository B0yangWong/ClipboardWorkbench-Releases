# 剪切板工作台

个人开发的原生 macOS 剪切板工具。这个仓库只提供应用下载、使用说明和问题反馈，**不包含应用源码**，也不包含开发者的剪切板历史。

## 下载

[下载 0.1.1 测试版](https://github.com/B0yangWong/ClipboardWorkbench-Releases/releases/tag/v0.1.1)

适用于 Apple 芯片 Mac（M 系列）。已在开发者的 macOS 27 上测试；最低部署目标是 macOS 14，但较早系统和 Intel Mac 尚未验证。无需安装 Xcode。

**这是未公证的测试版，不是正式发行版。** 当前应用使用本机临时签名，没有 Developer ID 签名或 Apple 公证。首次打开可能被 macOS 拦截，签名完整性检查和 SHA-256 校验不等于 Apple 安全审核通过。

## 安装与使用

1. 从发布页下载 `ClipboardWorkbench-0.1.1-macOS-arm64.zip`，解压后把“剪切板工作台.app”移到“应用程序”。
2. 自行确认下载来源，并参阅 [Apple 关于未知开发者应用的说明](https://support.apple.com/guide/mac-help/mh40616/mac)。不要关闭系统整体安全检查；若提示已损坏或恶意软件，停止打开并反馈提示原文。
3. 打开应用，按 Option + 空格唤醒快速小窗；点击 Dock 图标或按 Command + Shift + M 打开管理窗口。
4. 应用设置可暂停记录、清空历史和拖拽临时文件。关闭窗口不等于退出应用；从应用菜单退出才能停止后台运行。
5. 安装后应用会尝试注册登录启动。在系统设置“通用 > 登录项”检查状态，可以自行禁用；登录启动尚未完成真实重新登录验证。

## 功能

- 本地保留最近 50 条文字、图片和文件记录，重启后恢复；只去除连续重复内容。
- mini 小窗滚动查看最近 30 条，主窗口支持文字搜索、类型筛选、列表、网格和预览。
- Command + 单击、多选框、边缘滚动、全选、批量复制和拖拽。
- 通过 macOS 原生隔空投送分享图片和文件，需要用户主动操作。
- 两个窗口都不默认置顶，应用显示在 Dock。

## 隐私与安全

请在使用前阅读 [隐私说明](PRIVACY.md)。应用会读取复制过的内容，其中可能有密码、验证码和私人文件路径。

历史仅保存在本机，应用自身没有自动上传历史、分析统计或自动更新功能。带常见敏感、临时标记的内容会被跳过，但**无法识别所有密码和敏感内容**。本地历史没有独立加密；同一账户的其他程序和管理员仍可能访问，建议在复制敏感信息前暂停记录。

文件记录只保存原文件位置，不备份原文件。批量粘贴取决于接收应用。隔空投送、快捷键、跨应用拖拽和登录启动仍需要在不同设备上继续验证。
